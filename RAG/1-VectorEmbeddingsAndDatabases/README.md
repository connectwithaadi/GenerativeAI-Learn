# 🧠 Vector Embeddings & Embedding Models

A hands-on learning module focused on **vector embeddings, pretrained embedding models, and semantic similarity** using Python, NumPy, Hugging Face, and OpenAI.

This module explores how text is represented as numerical vectors, how embedding models convert text into vector representations, and how cosine similarity can be used to compare vectors and build the foundation for semantic search.

The goal is to develop a strong understanding of embeddings before moving into vector databases, advanced retrieval, and Retrieval-Augmented Generation (RAG).

---

## 🎯 Learning Objectives

- Understand the fundamentals of vector embeddings.
- Represent words and text as numerical vectors.
- Visualize vectors in a simplified embedding space.
- Understand embedding dimensions and vector representations.
- Generate embeddings using Hugging Face models.
- Generate embeddings using OpenAI's embedding API.
- Calculate cosine similarity between vectors.
- Compare semantic similarity between sentences.
- Implement a basic semantic search function.
- Prepare for vector storage and retrieval workflows.

## 🧠 What Are Vector Embeddings?

Vector embeddings are numerical representations of information, such as words, sentences, or documents.

An embedding model maps an input into a vector in a multidimensional space. These vectors can then be compared using mathematical similarity measures.

For example:

```text
Input Text
    |
    v
Embedding Model
    |
    v
Numerical Vector
    |
    v
Similarity Comparison
```

Real embedding models can produce vectors with hundreds or thousands of dimensions, depending on the selected model and configuration.

The purpose of an embedding is to create a representation that supports useful comparisons for a particular task.

---

## 📐 Understanding Cosine Similarity

Cosine similarity compares the directions of two nonzero vectors.

\[
\operatorname{cosine}(A,B)
=
\frac{A\cdot B}{\|A\|\|B\|}
\]

| Score | General Interpretation |
|---|---|
| Close to `1` | Similar vector directions |
| Close to `0` | Approximately perpendicular vectors |
| Close to `-1` | Opposite vector directions |

Cosine similarity is frequently used in embedding-based retrieval. However, its scores should be interpreted in the context of the embedding model and the application.

## ⚠️ Scope and Limitations

- The fundamentals notebook uses illustrative, manually defined vectors.
- Hugging Face and OpenAI modules use different embedding implementations.
- Model comparisons are not necessarily based on controlled benchmarks.
- The OpenAI module requires external API access.
- Semantic search in the OpenAI notebook is an in-memory implementation.
- Persistent vector storage and end-to-end RAG question answering are not implemented in these three modules.
