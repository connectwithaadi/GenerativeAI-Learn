### 1. What Are Embeddings?

Embeddings represent information as numerical vectors that machine learning systems can process.

The notebook introduces this concept using simplified two-dimensional vectors for six words:

|---|---:|---:|
| `cat` | 0.80 | 0.60 |

### 3. Measuring Similarity with Cosine Similarity

The notebook implements a `cosine_similarity()` function using NumPy.

```python
def cosine_similarity(vec1, vec2):
    dot_product = np.dot(vec1, vec2)
    norm_a = np.linalg.norm(vec1)
    norm_b = np.linalg.norm(vec2)

    return dot_product / (norm_a * norm_b)
```

Cosine similarity compares two vectors based on the angle between them.

Mathematically:

\[
\operatorname{cosine}(A,B)
=
\frac{A\cdot B}{\|A\|\|B\|}
\]

For nonzero vectors, the result lies between \(-1\) and \(1\).

| Value | General interpretation |
|---|---|
| Close to `1` | Vectors point in similar directions |
| Close to `0` | Vectors are approximately perpendicular |
| Close to `-1` | Vectors point in opposite directions |

A cosine similarity near zero does not universally mean that two concepts are unrelated; interpretation depends on the embedding model and data.

### 4. Comparing Similar and Dissimilar Vectors

The notebook defines three example vectors:

```python

```

It then compares:

- `cat_vector` with `kitten_vector`
- `cat_vector` with `car_vector`

The first pair points in similar directions, while the second pair points in substantially different directions.

The notebook calculates and displays the cosine similarity values to demonstrate how the metric compares vector orientations.

**Key takeaway:** Cosine similarity is a fundamental mathematical operation used in many embedding-based similarity and retrieval systems.
